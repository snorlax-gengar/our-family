## 🌟 프로젝트 개요 & 핵심 철학

**우리가 (우리家)**는 내집마련을 준비하는 부부와 가족들을 위해 탄생한 맞춤형 부동산 & 금융 종합 플랫폼입니다.  
과도한 영끌(LTV 80%)에 따른 리스크를 방지하고 정부의 가계부채 관리 및 실수요자 지원 정책에 맞추어 **실질적이고 안전한 LTV 70% 기준**을 엄격히 적용하며, **생애최초 취득세 200만 원 감면**과 **DSR 미적용 초저금리 혜택**을 정밀하게 시뮬레이션합니다.

## 🚀 주요 기능

### 1. 서울 & 경기 5~6억 원대 아파트 매물 & 신생아 특례대출 시뮬레이터
- **지역별 분류 & 세부 구/시 필터**:
  - **서울 권역**: 노원구(상계주공, 중계그린 등), 도봉구(창동주공19단지 등), 강북구(SK북한산시티 등), 구로구(개봉현대, 구로두산 등), 금천구(관악산벽산타운 등), 은평구(백련산힐스테이트 등), 중랑구(신내동성 등) 등 주요 역세권 대단지
  - **경기 북부/서부**: 고양시(후곡마을, 무원마을 등), 부천시(미리내마을 등), 김포시(풍무센트럴푸르지오 등) 등
  - **경기 남부/동부**: 수원시(매탄위브하늘채, 황골주공 등), 안양시(비산삼성래미안 등), 군포시(세종주공 등), 용인시(새천년그린빌 등), 시흥시(배곧한라비발디 등) 등
- **평형별 인터랙티브 CAD 도면(평면도) 뷰어**:
  - `59㎡ 2-Bay`: 24~25평형 실속 판상형 복도식/계단식 평면 (상계주공, 중계그린 등)
  - `59㎡ 3-Bay`: 24~25평형 준신축 3베이 혁신 평면 (방3/욕2, 매탄위브, 백련산힐스테이트, 풍무푸르지오 등)
  - `84㎡ 3-Bay`: 32~33평형 전통 국민평형 판상형 맞통풍 평면 (후곡마을, 무원마을, 미리내마을, 개봉현대 등)
  - `84㎡ 4-Bay`: 33~35평형 최신 4베이 신축 평면 (알파룸/드레스룸/대형팬트리, 배곧한라비발디 등)
  - 공간 호버 인터랙션 (상세 치수, 특징) 및 `확장형` vs `기본형` 모드 전환 토글
- **가격별 정렬 & 가격대 구간 빠른 필터**:
  - `💰 가격 낮은순 (4억대부터)` ⬇️ (기본 정렬)
  - `💰 가격 높은순 (~6억대)` ⬆️
  - `전세가율 높은순`, `신축·준신축순`, `대단지순`
- **정부 대출 정책 기준 안전 LTV 70% 준수**:
  - 무리한 대출 한도 부풀리기(LTV 80%)를 배제하고 **LTV 70% 안전 상한선**을 기준으로 정밀 산출
  - **생애최초 주택구입 시 취득세 최대 200만 원 전액 감면** 혜택 자동 계산
  - **방공제(5,500만 원) & MCG 모기지신용보증** 가입 연동
  - **DSR 스트레스 2단계 전면 미적용**: 연 1.6%~3.3% 초저금리로 최대 5억 원 지원
  - 취득세 + 중개보수 포함 **최종 필요 현금 총액 견적서** 제공

## 🌐 무료 배포 가이드 (Cloudflare Pages + GitHub, 서버 없음)

이 프로젝트는 **서버 없이 동작하는 정적 사이트**입니다.
- 단지·금리·정책 데이터는 빌드할 때 JSON(`frontend/public/data/`)으로 내보내고, 대출 계산은 브라우저에서 합니다(`frontend/src/lib/loanCalculator.js`).
- 금리·뉴스·정책은 GitHub Actions(`.github/workflows/daily-data-sync.yml`)가 30분마다 수집해 내용이 바뀐 경우에만 커밋하고, 커밋이 들어오면 Cloudflare Pages가 자동으로 다시 빌드합니다.
- 빌드할 때 단지별 검색용 페이지(`/apt/<단지id>/`), `sitemap.xml`, `robots.txt`가 함께 생성됩니다.
- 관심 단지·숨긴 단지는 각 사용자의 브라우저(localStorage)에 저장됩니다.

### [1단계] GitHub에 푸시
```bash
git add -A
git commit -m "feat: 정적 사이트 전환 (Cloudflare Pages)"
git push origin main
```

### [2단계] Cloudflare Pages 프로젝트 만들기
1. [Cloudflare 대시보드](https://dash.cloudflare.com) → **Workers & Pages** → **Create** → **Pages** → **Connect to Git** 에서 이 저장소를 선택합니다.
2. 빌드 설정:
   - **Framework preset**: None
   - **Root directory**: `/` (비워 두기)
   - **Build command**: `npm run build`
   - **Build output directory**: `frontend/dist`
   - **Environment variables**: `SITE_URL` = 실제 서비스 주소 (예: `https://wooriga.pages.dev` 또는 연결한 도메인)
   - Node 버전은 저장소 루트의 `.node-version`(22)을 따릅니다.
3. **Save and Deploy** 후 몇 분 뒤 `https://<프로젝트명>.pages.dev` 로 접속할 수 있습니다.

### [2-1단계] 30분 주기 자동 수집 연결 (Cloudflare Cron → GitHub Actions)
GitHub 자체 예약 실행은 지연·누락이 잦아, Cloudflare Worker의 Cron(`wrangler.jsonc` → `triggers.crons`, 매시 7·37분)이 수집 워크플로를 실행시킵니다(`worker/index.js`).
1. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
   - Repository access: **Only select repositories** → `our-family`
   - Permissions → Repository permissions → **Actions: Read and write** (나머지는 기본값)
2. Cloudflare → Workers & Pages → `our-family` → **Settings → Variables and Secrets → Add**
   - Type: **Secret**, Name: `GITHUB_TOKEN`, Value: 위 토큰
3. 확인: Cloudflare 프로젝트의 **Logs**(또는 Observability)에서 매시 7·37분에 `데이터 수집 워크플로 실행 요청 완료` 로그,
   GitHub Actions 탭에서 `workflow_dispatch` 실행이 30분마다 보이면 정상입니다.
   토큰이 만료되면 401 오류가 찍히므로 새 토큰으로 교체하세요. (그동안에도 GitHub 자체 예약이 3시간마다 보조로 실행됩니다.)

### [3단계] 검색 등록
- `frontend/index.html` 의 `naver-site-verification` / `google-site-verification` 주석을 풀고 인증 코드를 넣은 뒤 푸시합니다.
- 네이버 서치어드바이저와 구글 서치콘솔에 `<사이트주소>/sitemap.xml` 을 제출합니다.
- 도메인을 바꾸면 Cloudflare의 `SITE_URL` 환경변수만 바꾸고 다시 배포하면 canonical·sitemap 주소가 함께 바뀝니다.

## 💻 로컬(내 컴퓨터)에서 실행하기

```bash
cd d:\my-realestate-app
npm run install:all   # 처음 한 번
npm run dev           # 데이터 내보내기 후 http://localhost:5173 개발 서버 실행
```

배포본과 같은 결과물을 확인하려면 `npm run build` 후 `frontend/dist` 를 정적 서버로 열면 됩니다.
(기존 Express 서버 `npm start` / `start-app.bat` 도 빌드된 화면을 그대로 보여주지만, 화면은 더 이상 `/api` 를 사용하지 않습니다.)

## 🛠️ 기술 스택
- **Frontend**: React 19, Vite, Tailwind CSS v4, Lucide React (FinTech UI)
- **Interactive CAD**: Scalable Vector Graphics (SVG) Architectural Floor Plan Viewer
- **Backend**: Node.js, Express.js
- **Scraper & Engine**: Axios, Cheerio, RSS-Parser, 국토부 실거래가 및 KB부동산 시세 연동 모듈
- **Design Philosophy**: 가족을 위한 직관적이고 따뜻한 금융/부동산 UX
